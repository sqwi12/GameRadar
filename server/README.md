# gameradar_server

REST API GameRadar на Dart Frog. Работает только с нашей базой PostgreSQL. В Steam ходит только worker.

## Эндпоинты

Все ответы в JSON, ключи в `snake_case`, цены в минимальных единицах валюты. Ошибки приходят с телом `ApiError`: `{"code": "...", "message": "...", "fields": [{"field": "...", "code": "..."}]}`.

| Метод и путь | Токен | Описание |
|---|---|---|
| `GET /health` | — | Проверка, что сервер жив |
| `POST /auth/anonymous` | — | Вход по ID устройства → `AuthResponse` с JWT на 7 дней |
| `GET /me` | ✔ | Профиль и настройки |
| `PUT /me/settings` | ✔ | Заменить настройки целиком (`UserSettings`) |
| `GET /games/search?q=&region=&limit=` | — | Поиск по названию |
| `GET /games/top?sort=current\|peak_24h&only_discounted=&offset=&limit=` | — | Топ по онлайну |
| `GET /games/discounts?sort=discount\|price\|players&min_discount_pct=&max_price=&offset=&limit=` | — | Скидки сейчас |
| `GET /games/{appId}?region=` | — | Экран игры (`GameDetails`) |
| `GET /games/{appId}/players?period=24h\|7d\|30d` | — | График онлайна |
| `GET /games/{appId}/prices?region=` | — | История изменений цены |
| `GET /games/{appId}/header?v=` | — | Обложка игры из нашей БД (кэш на год, ETag, 304) |
| `GET /watchlist` | ✔ | Список отслеживания |
| `PUT /watchlist/{appId}` | ✔ | Добавить (201) или изменить пороги (200) |
| `DELETE /watchlist/{appId}` | ✔ | Удалить (204) |
| `PUT /devices` | ✔ | Зарегистрировать FCM-токен (204) |
| `DELETE /devices` | ✔ | Удалить FCM-токен, тело `{"fcm_token": "..."}` (204) |

Токен передаётся в заголовке `Authorization: Bearer <jwt>`.

## Поведение

- **Вход.** Сервер хранит только SHA-256 от ID устройства. Повторный вход с тем же ID возвращает того же пользователя, его настройки при этом не меняются. Неизвестный часовой пояс с устройства заменяется на `Asia/Almaty`.
- **Поиск.** Сначала точное совпадение, затем совпадение с началом названия, затем популярность (подписчики, онлайн) и похожесть. Символы `%` и `_` в запросе ищутся буквально.
- **Обложки.** В ответах API поле `header_image_url` — это наш путь `/games/{id}/header?v=<etag>` или его отсутствие. Адрес Steam не отдаётся никогда (правило 1), тест это проверяет.
- **Скидки.** Цены, проверенные больше 12 часов назад, не показываются. Иначе закончившаяся распродажа у игры, которую перестали отслеживать, висела бы в списке.
- **Экран игры** ставит отметку просмотра (`games.viewed_at`). Worker сутки обновляет такие игры наравне с отслеживаемыми, поэтому у игры из поиска быстро появляются цена и онлайн.
- **Список отслеживания.**
  - Не больше 200 игр, иначе ответ 409 `limit_exceeded`.
  - Регион фиксируется при добавлении.
  - При смене порогов сбрасывается отметка последнего уведомления.

## Запуск без Docker

Нужен `.env` в корне монорепо (см. `.env.example`): `DATABASE_URL` и `JWT_SECRET`.

```bash
dart pub global activate dart_frog_cli
dart_frog dev                 # с горячей перезагрузкой, http://localhost:8080
```

## Тесты

```bash
dart test                     # JWT и конфигурация; с TEST_DATABASE_URL — ещё и API на настоящей БД
dart test -t db               # только интеграционные тесты API (пересоздают схему тестовой БД!)
```
