# gameradar_app

Мобильное приложение GameRadar (Flutter, Android и iOS). Работает только с нашим API и никогда не обращается к Steam напрямую.

## Стек

| Задача | Пакеты |
|---|---|
| UI | `material_ui` — Material 3, вынесенный из Flutter в отдельный пакет; используется вместо `package:flutter/material.dart` |
| Состояние | `flutter_riverpod` + `riverpod_generator` |
| Навигация | `go_router`: `StatefulShellRoute` с четырьмя вкладками |
| Сеть | `dio` + `AuthInterceptor` |
| Офлайн-кэш | `drift` (SQLite) |
| Секреты | `flutter_secure_storage`: ID устройства и токен |
| Локализация | `flutter gen-l10n`, файлы `lib/l10n/app_ru.arb` и `app_en.arb` |

## Структура

```
lib/
├── main.dart                 запуск: БД, локальные настройки, фоновый вход
├── app.dart                  MaterialApp.router: тема, язык, навигация
├── core/
│   ├── cache/                CachedResource — «сначала кэш, потом сеть»
│   ├── config/               адрес API (--dart-define=API_BASE_URL=...)
│   ├── database/             drift: кэш ответов и локальные настройки
│   ├── network/              AuthInterceptor, AppException
│   ├── router/               маршруты и каркас с нижней навигацией
│   ├── storage/              защищённое хранилище, хранилище настроек
│   ├── theme/                светлая и тёмная темы
│   └── widgets/              загрузка, ошибка, пусто, «Обновлено N мин назад»
├── features/<фича>/{data,domain,presentation}
└── l10n/                     ARB-файлы и сгенерированный код
```

## Как это работает

- **Вход.** При первом запуске создаётся случайный UUID устройства (аппаратные ID не используются), приложение входит анонимно и получает JWT. `AuthInterceptor` добавляет токен ко всем запросам. За сутки до истечения токен обновляется, а на ответ 401 приложение один раз входит заново и повторяет запрос.
- **Кэш (правило 10).** `CachedResource` сразу отдаёт сохранённые данные из drift, затем обновляет их, если они устарели. Pull-to-refresh срабатывает не чаще раза в минуту. Время последнего обновления показывает виджет `LastUpdatedLabel`. Ошибка сети кэш не стирает.
- **Тема и язык** хранятся на устройстве и читаются до первого кадра, поэтому при запуске ничего не «мигает». Выбранный язык отправляется на сервер, чтобы push-уведомления приходили на нём же.

## Запуск

Нужен запущенный сервер (см. `server/README.md`). Эмулятор Android обращается к нему по адресу `10.0.2.2:8080`.

```bash
flutter run
flutter run --dart-define=API_BASE_URL=http://192.168.1.10:8080   # настоящее устройство в той же сети
```

HTTP без TLS разрешён только в debug-сборке (Android) и только к локальной сети (iOS).

## Тесты

```bash
flutter test
```

На Windows с Flutter 3.47.7 процесс `flutter_tester` изредка аварийно завершается (код `0xC0000005`), даже на тесте с одним виджетом `Text`. Тогда тесты помечаются как «did not complete». Это сбой движка, а не кода: перезапустите тесты.
