# gameradar_app

Мобильное приложение GameRadar (Flutter, Android и iOS). Работает только с нашим API и никогда не обращается к Steam напрямую.

## Стек

| Задача | Пакеты |
|---|---|
| UI | `CupertinoApp` (iOS-стиль) и [`liquid_glass_widgets`](https://pub.dev/packages/liquid_glass_widgets) 1.8.1 — Liquid Glass как в iOS 26: шейдерное стекло, «жидкие» анимации, блики |
| Состояние | `flutter_riverpod` + `riverpod_generator` |
| Навигация | `go_router`: `StatefulShellRoute` с четырьмя вкладками |
| Сеть | `dio` + `AuthInterceptor` |
| Офлайн-кэш | `drift` (SQLite) |
| Секреты | `flutter_secure_storage`: ID устройства и токен |
| Локализация | `flutter gen-l10n`, файлы `lib/l10n/app_ru.arb` и `app_en.arb` |

## Структура

```
lib/
├── main.dart                 запуск: БД, локальные настройки, фоновый вход
├── app.dart                  MaterialApp.router: тема, язык, навигация
├── core/
│   ├── cache/                CachedResource — «сначала кэш, потом сеть»
│   ├── config/               адрес API (--dart-define=API_BASE_URL=...)
│   ├── database/             drift: кэш ответов и локальные настройки
│   ├── network/              AuthInterceptor, AppException
│   ├── router/               маршруты и каркас с нижней навигацией
│   ├── storage/              защищённое хранилище, хранилище настроек
│   ├── theme/                палитра, темы, фон AppBackground под стеклом
│   └── widgets/              GlassScreen, загрузка, ошибка, пусто, «Обновлено N мин назад»
├── features/<фича>/{data,domain,presentation}
└── l10n/                     ARB-файлы и сгенерированный код
```

## Дизайн: Liquid Glass

- **Стекло только для навигации и управления**, как в iOS 26: шапки экранов, плавающая панель вкладок, круглые кнопки, переключатели и группы настроек. Контент (списки, текст) остаётся непрозрачным, чтобы его было легко читать.
- **Фон `AppBackground`** — почти чёрный синий (или светлый) градиент с одним мягким бирюзовым свечением сверху. Стеклу нужен неоднородный фон, но без узоров, чтобы он не спорил с контентом.
- **Сдержанная палитра.** Яркие цвета только у двух вещей: бирюзовый акцент (место в топе 1–3, онлайн на экране игры, кнопки) и зелёный у скидок. Онлайн в списках нейтральный, бейдж скидки — зелёный текст на приглушённой подложке. Цифры (цены, онлайн) с моноширинными цифрами (`AppText.tabular`).
- **Строка списка `GameTile`:** место в топе — плашкой на обложке, название сверху, внизу онлайн слева и цена справа. Цена со скидкой всегда в две строки (старая цена и бейдж, под ними итоговая), поэтому колонка цен ровная.
- **Край прокрутки** в `GlassScreen`: под стеклянной шапкой контент плавно уходит в фон и не просвечивает сквозь заголовок.
- **Каркас вкладок** (`HomeShell`) — один `GlassScaffold` с фоном и `GlassTabBar.bottom`. Экраны вкладок (`GlassScreen`) прозрачные и добавляют только свою стеклянную шапку, поэтому стекло шапки и панели преломляет один общий фон.
- **Правило пакета:** интерактивное стекло (переключатели, кнопки) не кладётся внутрь стеклянных карточек, иначе возникает двойное преломление.
- **Версия пакета закреплена (1.8.1).** В 1.7.2 при смене темы падала подсветка кнопок (#355), в 1.8.1 это исправлено. Новые версии выходят почти ежедневно, поэтому обновляться стоит осознанно и проверять на устройстве.

## Как это работает

- **Вход.** При первом запуске создаётся случайный UUID устройства (аппаратные ID не используются), приложение входит анонимно и получает JWT. `AuthInterceptor` добавляет токен ко всем запросам. За сутки до истечения токен обновляется, а на ответ 401 приложение один раз входит заново и повторяет запрос.
- **Кэш (правило 10).** `CachedResource` сразу отдаёт сохранённые данные из drift, затем обновляет их, если они устарели. Pull-to-refresh срабатывает не чаще раза в минуту. Время последнего обновления показывает виджет `LastUpdatedLabel`. Ошибка сети кэш не стирает.
- **Тема и язык** хранятся на устройстве и читаются до первого кадра, поэтому при запуске ничего не «мигает». Выбранный язык отправляется на сервер, чтобы push-уведомления приходили на нём же.

## Иконка

Радар с «засечкой» (найденной скидкой) на тёмном фоне. Исходники рисует `tool/make_icon.py` (Python, Pillow и NumPy) в `assets/icon/`: полная иконка для iOS и старых Android, а также фон, передний план и монохромный слой адаптивной иконки Android. Пересборка:

```
python tool/make_icon.py
dart run flutter_launcher_icons
```

`flutter_launcher_icons` 0.14 ошибочно меняет `ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS` в `ios/Runner.xcodeproj/project.pbxproj`. После генерации это изменение нужно откатить: `git checkout -- ios/Runner.xcodeproj/project.pbxproj`.

## Экраны

| Экран | Что есть |
|---|---|
| Топ по онлайну | сортировка «Сейчас / Пик за 24 ч», фильтр «Со скидкой», место в топе, бесконечная прокрутка |
| Скидки сейчас | сортировка по скидке, цене, онлайну; фильтры «от 25/50/75%» и «до 2 500 / 5 000 / 10 000 ₸» |
| Поиск | по 190+ тыс. игр, задержка ввода 350 мс, при наборе показываются прошлые результаты |
| Игра | обложка, разработчик и год, место в топе, отзывы, цена со скидкой, онлайн и пики, график за 7 дней (fl_chart), описание на языке приложения, жанры |
| Отслеживаемые | цена, пороги, «Цель достигнута» (такие игры наверху) |
| Лист «Уведомить, когда…» | цена не выше (₸) и/или скидка не меньше (слайдер), удаление из списка |
| Настройки → Steam | импорт списка желаемого: ссылка на профиль или ник, порог «скидка от 25/50/75%», статус импорта и подсказка для скрытого профиля, «Синхронизировать сейчас», «Отвязать профиль» |

На всех экранах со списками сначала показывается кэш, потом свежие данные. Работают pull-to-refresh (не чаще раза в минуту, иначе тост) и подпись «Обновлено N мин назад». Без сети показываются сохранённые данные с пометкой, без кэша — ошибка с «Повторить».

**Обложки игр приложение берёт только с нашего сервера** (`/games/{id}/header?v=...`). Их скачивает worker через общую очередь и лимит запросов, хранит PostgreSQL. `resolveImageUrl` отклоняет любой адрес не с домена API, поэтому даже пришедшая по ошибке ссылка на Steam не будет загружена (правило 1).

Импортированные игры в отслеживаемых помечены «Из списка желаемого Steam». Пока импорт в очереди, настройки опрашивают статус раз в 5 секунд и по завершении перезагружают список. Ссылку проверяет `SteamProfileRef.tryParse` ещё до отправки; к Steam приложение не обращается и здесь.

## Плавность

Замер времени кадров: сборка с флагом пишет в журнал раз в 3 секунды среднее время и 90-й перцентиль подготовки и отрисовки кадра, а также число кадров дольше 16 мс.

```
flutter run --profile --dart-define=PERF_LOG=true
adb logcat -s flutter
```

Оценивать плавность нужно в profile- или release-сборке: отладочная (`flutter run`) в разы медленнее, так задумано. На эмуляторе Android отрисовка через слой трансляции видеокарты занимает около 10 мс на кадр при любом содержимом, поэтому окончательно проверять плавность лучше на телефоне.

Что уже сделано для плавной прокрутки:
- нижняя панель без живого размытия: оно пересчитывалось на каждом кадре;
- обложки декодируются в размере показа (`memCacheWidth`), а не 460×215;
- скругления — обычные прямоугольные вместо суперэллипса;
- фон закэширован отдельным слоем (`RepaintBoundary`);
- в строке списка нет `IntrinsicHeight`, каждая строка измеряется один раз.

## Push-уведомления

- `PushService` при запуске регистрирует FCM-токен на сервере (`PUT /devices`), если разрешение уже выдано. Разрешение спрашивается не при старте, а когда пользователь задаёт порог цены или включает уведомления в настройках.
- Пока приложение открыто, уведомления показываются через flutter_local_notifications (канал `price_alerts`). Нажатие открывает экран игры.
- В настройках: статус push, «Уведомлять о ценах» и тихие часы (они хранятся на сервере, учитывает их worker).
- Firebase подключается, только если есть `android/app/google-services.json`. Без него приложение собирается и работает, просто без push.

## Запуск

Нужен запущенный сервер (см. `server/README.md`). Эмулятор Android обращается к нему по адресу `10.0.2.2:8080`.

```bash
flutter run
flutter run --dart-define=API_BASE_URL=http://192.168.1.10:8080   # настоящее устройство в той же сети
```

HTTP без TLS разрешён только в debug-сборке (Android) и только к локальной сети (iOS).
